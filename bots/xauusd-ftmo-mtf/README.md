# XAUUSD · WaveTrend multi-timeframe

Il [sorgente MQL5](FTMO_XAUUSD_WaveTrend.mq5) e il [prompt tecnico v2](Prompt_FTMO_WaveTrend_v2.pdf) descrivono questa variante. Il timeframe di ingresso iniziale è M15. Gli input consentono di abilitare separatamente le conferme M30, H1 e H4.

Il progetto prevede sia un indicatore personalizzato denominato `WT_LB` sia un calcolo nativo del WaveTrend. SL e TP derivano da importi monetari configurabili, inizialmente 100 ciascuno. Questi parametri appartengono alla variante multi-timeframe.
